The Writer's Project Poetris

How to Play

Controls:

  • Arrow Keys: Move the falling word left and right
  • Down Arrow or Space: Drop the word immediately
  • Touch/Swipe: Swipe left/right to move, swipe down to drop

Gameplay:

  • Words fall from the top and you position them in columns
  • When a row is completely filled, those words move to the completed text area
  • Delete blocks (←) remove the bottom word in a column
  • Adjust the delete ratio to control how often delete blocks appear
  • Use the Corpus button to change the source text for word generation

Game Options

Controls how often delete blocks (←) appear. Higher values create more dynamic, shifting compositions.

Modify the source text that generates your word blocks. Add multiple texts to create hybrid compositions.
